## Required corrections

### R1 — Niche-definition IDs identify parameters, not the supplied definition

`src/regkg/project_data/contexts.py:124` hashes dataset, focal type, k,
resolution, pooled conditions, and method. It omits the neighborhood source
identity or any externally supplied producing-run identity.

Reproduction: build the existing tiny synthetic project; change the AT1 niche_1
neighbor counts from `10,10,4,1` to `11,9,4,1` (still sums to 25), then ingest.
Both ingestions succeed with different artifact and neighborhood source IDs,
but the AT1 definition-run IDs and niche-state IDs are identical. Different
supplied definitions can therefore collapse into the same future graph node.

Minimal correction: include the already available focal neighborhood source ID
in the deterministic definition identity. Document that this is a local
content-qualified definition identifier, not a recovered Yale clustering-run
accession. Do not invent a producing-run ID. Keep condition excluded from niche
identity, and preserve identical-input replay and unaffected focal-type IDs.

### R2 — Observation identity omits its resolved context/niche assignment

`src/regkg/project_data/expression.py:69` and
`src/regkg/project_data/chromlinker.py:80` identify measurements using source,
gene(s), and raw context label only. The resolved context and niche are mutable
payload under those IDs.

Reproduction: keep all synthetic matrix bytes unchanged and change only the
configured model system. Ingestion succeeds and produces different context IDs,
but every expression and ChromLinker observation ID stays unchanged. Loading both
artifacts by observation ID could overwrite or multiply context links. After R1,
a revised niche definition would produce the analogous niche-link conflict.

Minimal correction: qualify these observation identities with their resolved
`context_id` and nullable `niche_state_id`, retaining source and gene identity.
Also include resolved `context_id` in signature comparison identity so signature
row/comparison IDs cannot stay unchanged when their biological context changes.
Check biological-context identity against its scientific fields, including the
configured disease annotation; differing known context facts must not silently
share one immutable context identity. Keep source IDs independently traceable.
Do not use execution timestamps, machine paths, or the entire artifact key in
semantic IDs. P2 identifier enrichment must still preserve existing local gene
and observation IDs when their scientific assignments are unchanged.

The reviewer ran these probes only on temporary synthetic inputs. Boolean
