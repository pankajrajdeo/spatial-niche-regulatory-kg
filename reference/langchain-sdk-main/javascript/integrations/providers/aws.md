# AWS integrations

> Integrate with AWS using LangChain JavaScript.

All functionality related to the [Amazon AWS](https://aws.amazon.com/) platform.

## Chat models

### Bedrock Converse

See a [usage example](../chat/bedrock_converse.md).

```typescript
import { ChatBedrockConverse } from "@langchain/aws";
```

## Text embedding models

### Bedrock

See a [usage example](../embeddings/bedrock.md).

```typescript
import { BedrockEmbeddings } from "@langchain/aws";
```

## Retrievers

### Knowledge bases for Amazon Bedrock

See a [usage example](../retrievers/bedrock-knowledge-bases.md).

```typescript
import { AmazonKnowledgeBaseRetriever } from "@langchain/aws";
```
