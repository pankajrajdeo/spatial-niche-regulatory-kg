# August 2026: LangChain Newsletter

This month, Harrison talks about why owning your intelligence matters more than ever.

Also new: Managed Deep Agents and LLM Gateway hit public beta. Keep on reading to see what's new at LangChain.

## LangSmith Updates

🤖 [**Managed Deep Agents Public Beta**](https://www.langchain.com/blog/introducing-managed-deep-agents/)**:** Deploy your Deep Agent to a managed LangSmith runtime with one command, with durable execution, sandboxes, tracing, and more built in.

🔐 [**LLM Gateway Public Beta**](https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents/)**:** LLM Gateway sits between your agents and the models they call, providing the controls that teams need first when agents go into production: cost controls, rate limits, model fallbacks, and sensitive data handling.

🏎️ [**LangSmith Engine Performance Improvements**](https://www.langchain.com/blog/new-in-langsmith-engine-2x-better-issue-detection/)**:** Engine is now more than 2x better at finding agent issues, with proposed fixes that perform 25% better on standard benchmarks.

⚖️ [**Tuned Evaluators**](https://www.langchain.com/blog/introducing-langsmith-tuned-evaluators-starting-with-perceived-error/)**:** Automatically attach quality feedback to production traces, so you can find and fix agent mistakes without managing your own judge. Our first Tuned Evaluator is Perceived Error.
[Watch an intro to Tuned Evaluators →](https://events.langchain.com/customer-ama-august/)

☁️ [**Bring Your Own Cloud**](https://www.langchain.com/blog/langsmith-byoc-is-now-generally-available-on-aws/)**:** BYOC is now available on AWS, so teams can run LangSmith in their own VPC while LangChain handles setup, scaling, and upgrades.

## Open Source

🔧 [**Deep Agents v0.7:**](https://www.langchain.com/blog/deep-agents-v0-7/) This release simplifies the base harness, resulting in 65% fewer base input tokens at comparable performance.
